## 使用 AI 时需要注意什么？

无论使用官方 ChatGPT 还是第三方 AI 平台，都建议养成基本的安全习惯。

### 1. 不要提交敏感信息

尽量不要把以下内容直接发送给 AI：

* 银行卡号
* 登录密码
* 短信验证码
* 身份证信息
* 公司内部机密
* 未公开的客户资料
* API 私钥

### 2. AI 的回答不一定完全正确

AI 可以大幅提高信息整理效率，但仍然可能生成错误信息。

尤其涉及医疗、法律、金融、安全等重要问题时，应通过专业人士或权威来源进一步核实。

### 3. 第三方平台和官网要区分

ChatGPT 官方产品由 OpenAI 提供。

第三方镜像、API 中转、聚合 AI 平台属于不同的服务提供方。在使用之前，应自行了解其隐私政策、数据处理方式和服务条款。
